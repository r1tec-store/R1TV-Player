# GitHub publishing steps / خطوات النشر على GitHub

1. Create a repository named `R1TV-Player`.
2. Read `NOTICE.md` and confirm that you are allowed to publish the app binary and its bundled components. Do not describe it as open source unless you have the source and a valid license.
3. Upload `README.md`, `FEATURES.md`, `NOTICE.md`, `PUBLISHING.md`, `.gitignore`, and the `screenshots/` folder.
4. Create a GitHub Release named `v1.0.0` and attach `release-assets/R1TV-Player-v1.0.0.apk` to the release. Keeping the APK as a Release attachment makes the repository history smaller.
5. Keep backup files, signing keys, passwords, test credentials, and private playlist links off the public repository.

## بالعربية

1. أنشئ مستودعا باسم `R1TV-Player`.
2. اقرأ `NOTICE.md` وتأكد من امتلاكك حق نشر ملف التطبيق ومكوناته المرفقة. لا تصفه كمشروع مفتوح المصدر دون امتلاك المصدر وترخيص صالح.
3. ارفع الملفات `README.md` و`FEATURES.md` و`NOTICE.md` و`PUBLISHING.md` و`.gitignore` ومجلد `screenshots/`.
4. أنشئ إصدارا في GitHub باسم `v1.0.0` وأرفق به `release-assets/R1TV-Player-v1.0.0.apk`. إرفاق APK كملف إصدار يقلل حجم سجل المستودع.
5. لا ترفع ملفات النسخ الاحتياطي أو مفاتيح التوقيع أو كلمات المرور أو بيانات الاختبار أو روابط القوائم الخاصة.
